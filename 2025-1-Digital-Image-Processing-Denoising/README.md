# Image Denoising

- 기간: 2025-04-30 ~ 2025-06-20
- 과목: 디지털영상처리
- 구분: 개인 프로젝트

## 내용

BSD300 이미지에 인공 노이즈를 추가한 뒤 고전적 필터와 DnCNN 기반 모델을 비교해 영상 복원 성능을 분석했다.

- 데이터셋 구성과 노이즈 추가
- Gaussian filter, Median filter 등 classical 방법 비교
- DnCNN의 layer 수와 filter 수를 바꾼 구조 실험
- PSNR과 SSIM을 이용한 정량 평가
- 결과 영상과 정답 영상 비교
- 추가 실험에서 학습 epoch와 모델 구조 변화에 따른 결과 확인

외부 데이터셋과 개인 경로는 저장하지 않고, 모델 구현과 실험 흐름을 정리한 노트북만 보관했다.
